# homebrew-cvtest-kun

[CVテスト君](https://github.com/mochitablog0326-lgtm/cvtest-kun) の Homebrew tap。

このディレクトリの中身を `mochitablog0326-lgtm/homebrew-cvtest-kun` リポジトリの
ルートに置いてください。リリース時に CI が `version` と `sha256` を書き換えて
PR を出します。

```bash
brew tap mochitablog0326-lgtm/cvtest-kun
brew install --cask cvtest-kun
```

homebrew-core は実績が必要で最初は通らないため、独自 tap から始めます。
